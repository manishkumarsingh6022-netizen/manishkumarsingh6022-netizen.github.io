MANISH SINGH — DEVELOPER PORTFOLIO
==================================

FILES
- index.html : website content and layout
- style.css  : black/red visual design, responsive layout, animations
- script.js  : mobile navigation, scroll reveal, current year

PREVIEW LOCALLY
1. Keep all three files in the same folder.
2. Double-click index.html to open it in a browser.
3. Internet is needed for the optional Google Fonts; the site itself works without them.

BEFORE PUBLISHING — PERSONALISE THESE DETAILS
1. In index.html, replace the LinkedIn link (currently https://www.linkedin.com/) with your profile URL.
2. Replace the GitHub link (currently https://github.com/) with your profile URL.
3. Replace hello@example.com with an email address you want to publish, or remove the Email link.
4. Add real project links when you have projects ready. The practice log is clearly marked as planned.
5. Check your course/institution details and update the page if you want to display them.

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to GitHub: https://github.com/
2. Create a PUBLIC repository named exactly: YOUR-GITHUB-USERNAME.github.io
3. Upload index.html, style.css, and script.js to the repository root.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch; choose main and /(root), then Save.
6. Wait a few minutes. Your website should appear at https://YOUR-GITHUB-USERNAME.github.io/

You can also follow the official guide:
https://docs.github.com/en/pages/quickstart

NOTE
This is a static portfolio starter. It does not collect form submissions or store personal data.
